# EnigmaX

**Uncover the Unknown.**

An entertainment web app featuring fictional mystery investigations, brain challenges, and branching interactive stories.

## Features
- Responsive dark interface
- Two fictional mystery cases
- Pattern, memory, and riddle challenges
- Interactive branching story
- Local XP and progress saved on the device
- Basic PWA offline caching
- No API key or backend required

## Files
- `index.html` — app structure
- `styles.css` — responsive design
- `app.js` — games and progress logic
- `manifest.json` — PWA metadata
- `service-worker.js` — offline caching

## Run locally
Open `index.html` in a browser for basic testing. Service worker installation and PWA/offline support require HTTPS or localhost; GitHub Pages provides HTTPS.

## Publish with GitHub Pages
1. Open repository **Settings → Pages**.
2. Under Build and deployment, choose **Deploy from a branch**.
3. Select branch `main` and folder `/ (root)`, then Save.
4. Wait for the published site URL to appear.
